# סקר טלפוני / קליקרים טלפוניים

תוכנה שמריצה סקר או הצבעה חיה (קליקרים) דרך שיחת טלפון רגילה: המשתתף מתקשר
למספר טלפון, שומע שאלה, ובוחר תשובה על ידי לחיצה על מקש במקלדת הטלפון (DTMF).

התוכנה תומכת בשני מצבים, וניתן לעבור ביניהם לכל סקר בנפרד:

- **סקר רציף** — כל מתקשר עובר *לבדו*, במהלך השיחה שלו, על כל השאלות ברצף
  (כמו סקר שביעות רצון טלפוני רגיל).
- **הצבעה חיה (קליקרים)** — כולם מצביעים בו-זמנית על אותה שאלה "פעילה"
  (למשל בכנס: המנחה מציג שאלה, הקהל מתקשר ולוחץ מקש, והתוצאות מתעדכנות
  בזמן אמת על המסך). המנחה עובר לשאלה הבאה בעצמו מתוך לוח הבקרה.

יש לוח ניהול (אדמין) מוגן בסיסמה שבו יוצרים סקרים, מוסיפים שאלות ואפשרויות,
רואים תוצאות חיות (גרף + טבלה), ומייצאים קובץ CSV לאקסל.

## איך זה בנוי

- **Node.js + Express** — שרת אחד שמטפל גם בשיחות הטלפון (webhooks של Twilio)
  וגם בלוח הניהול.
- **Twilio** — שירות הטלפוניה שמספק את מספר הטלפון, מנגן את השאלות בעברית
  (טקסט-לדיבור), ואוסף את הקשות המקשים.
- **SQLite** (קובץ מקומי, באמצעות `better-sqlite3`) — שומר את הסקרים, השאלות
  והתוצאות. אין צורך בשרת מסד נתונים נפרד.

## שלב 1: הקמת חשבון Twilio וקבלת מספר טלפון

1. היכנסו ל-twilio.com והירשמו לחשבון (יש תקופת ניסיון חינמית עם קרדיט).
2. בלוח הבקרה של Twilio, תחת **Phone Numbers → Buy a Number**, קנו מספר
   טלפון עם יכולת **Voice**. למספר ישראלי מקומי ייתכן ותידרש אימות עסקי
   (Regulatory Bundle) — לחלופין אפשר להתחיל עם מספר אמריקאי/בינלאומי לבדיקות.
3. שימרו בצד את **Account SID** ואת **Auth Token** מהעמוד הראשי של הלוח
   (לא חובה לקוד הזה, אך שימושי אם תרצו להרחיב בעתיד).

את חיבור המספר ל-webhook של השרת נעשה בשלב 3, אחרי שהשרת יהיה אונליין.

## שלב 2: פריסת השרת לאינטרנט (מומלץ: Render)

הקוד צריך לרוץ על שרת עם כתובת ציבורית, כי Twilio שולח אליו בקשות HTTP בזמן
שיחה. **Render.com** מציע אירוח Node.js פשוט וזול עם שכבה חינמית:

1. העלו את התיקייה הזו ל-GitHub (repo חדש).
2. ב-Render: **New → Web Service**, חברו את ה-repo.
3. הגדרות הבנייה וההרצה:
   - Build Command: `npm install`
   - Start Command: `node server.js`
4. תחת **Environment**, הוסיפו משתני סביבה (ראו `.env.example`):
   - `ADMIN_PASSWORD` — סיסמה ללוח הניהול (שם המשתמש תמיד `admin`).
   - `VOICE_WEBHOOK_SECRET` — מחרוזת סודית כלשהי, שתגן על נקודות הקצה
     הטלפוניות מגישה זרה.
   - `DB_PATH` — אפשר להשאיר `./data/survey.db`.
5. **חשוב — שמירת הנתונים:** בשכבה החינמית של Render מערכת הקבצים אינה
   קבועה, כך שקובץ ה-SQLite עלול להימחק באתחול מחדש. לשימוש אמיתי (לא רק
   בדיקה), שדרגו לתוכנית **Starter** (משולמת, זולה) והוסיפו שם **Persistent
   Disk** שמחובר לנתיב `/opt/render/project/src/data`. לחלופין, ייצאו CSV
   אחרי כל אירוע כגיבוי.
6. לאחר הפריסה תקבלו כתובת ציבורית, למשל:
   `https://phone-survey-xyz.onrender.com`

(גם Railway.app עובד טוב ומציע נפח אחסון קבוע גם בתוכניות הזולות — זו
אלטרנטיבה סבירה אם חשיבות שמירת הנתונים גבוהה מההתחלה.)

## שלב 3: חיבור מספר הטלפון לשרת

בלוח הבקרה של Twilio, תחת **Phone Numbers → Manage → Active Numbers**,
בחרו את המספר שקניתם, ותחת **Voice Configuration**:

- **A call comes in**: Webhook
- כתובת: `https://<הכתובת-שלכם>/voice/incoming?key=<VOICE_WEBHOOK_SECRET>`
  (השתמשו באותו ערך סודי שהגדרתם בשלב 2)
- Method: `HTTP POST`

שמרו. מעכשיו, כל שיחה נכנסת תתחיל את הסקר הפעיל.

## שלב 4: שימוש בלוח הניהול

גלשו ל- `https://<הכתובת-שלכם>/admin` והתחברו עם שם משתמש `admin` והסיסמה
שהגדרתם.

1. **צרו סקר** — תנו שם, ובחרו "סקר רציף" או "הצבעה חיה".
2. **הוסיפו שאלות** — לכל שאלה כתבו את הטקסט, ואת האפשרויות בפורמט
   `מקש=טקסט`, שורה אחת לכל אפשרות, למשל:
   ```
   1=מאוד מרוצה
   2=מרוצה
   3=לא מרוצה
   ```
   מקשים אפשריים: הספרות 0-9 (וגם `*` ו-`#`, אם כי מומלץ להישאר עם ספרות
   לנוחות המתקשרים).
3. **הפכו את הסקר ל"פעיל בקו הטלפון"** — רק סקר אחד יכול להיות פעיל בו-זמנית;
   זה הסקר שמתקשרים חדשים ישמעו.
4. **במצב הצבעה חיה**, לוח התוצאות מציג כפתורי "שאלה קודמת / שאלה הבאה" —
   כך תשלטו באיזו שאלה כולם מצביעים כרגע. אפשר גם "איפוס תוצאות" בין אירועים.
5. התוצאות (גרף + טבלה) מתעדכנות אוטומטית כל כמה שניות, ואפשר לייצא הכול
   כקובץ **CSV** לפתיחה באקסל בכל רגע.

## בדיקה מקומית (לפני פריסה, עם ngrok)

```bash
npm install
cp .env.example .env     # ומלאו ADMIN_PASSWORD ו-VOICE_WEBHOOK_SECRET
node server.js
```

כדי ש-Twilio יוכל להגיע למחשב שלכם, התקינו [ngrok](https://ngrok.com) והריצו:

```bash
ngrok http 3000
```

והשתמשו בכתובת שה-ngrok נותן (כמו `https://abcd1234.ngrok-free.app`) בתור
כתובת ה-webhook בשלב 3 לעיל, לצורך בדיקה בלבד.

## הערות

- קול הדיבור הוא **Polly.Ayelet** (קול עברי של Amazon, זמין דרך Twilio).
  אם מסיבה כלשהי הקול אינו זמין באזור החשבון שלכם, אפשר לערוך את
  `routes/voice.js` ולשנות את `VOICE_NAME`.
- נקודות הקצה `/voice/*` מוגנות במפתח סודי בכתובת (`?key=...`) ולא בסיסמה
  רגילה, כי Twilio לא תומך בטופס התחברות; לוח הניהול תחת `/admin` כן מוגן
  בסיסמה (Basic Auth).
- כל מתקשר מזוהה לפי `CallSid` (מזהה שיחה של Twilio) ולא לפי שם — מספר
  הטלפון המתקשר (`From`) נשמר בטבלת התוצאות אך לא מוצג בלוח התוצאות המצרפי.
